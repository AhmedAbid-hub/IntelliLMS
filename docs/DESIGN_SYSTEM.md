# Existing IntelliLMS design system

Extracted from [styles.css](../frontend/src/styles.css) and current components. This refactor changes no CSS, colors, typography, layout, spacing or design. Later CSS declarations and inline styles can override earlier rules; the list records them instead of pretending every screen uses one token palette.

## Typography and spacing

The root uses Inter, Segoe UI, Arial, sans-serif at 14px. Inter is a preferred family, not proof that a font was downloaded. H1 uses `clamp(25px, 2.4vw, 33px)`, weight 750 and line-height 1.25; H2 is 19px/700; H3 is 16px/700. Small text is 12px. Forms inherit the family. Shared PageHeader has its own preserved gradient/spacing in [shared.tsx](../frontend/src/components/shared.tsx).

Spacing is not a strict single scale. Existing CSS/component styles commonly use 4, 6, 8, 10, 12, 16, 18, 20, 24, 28 and 32px, flexible grid gaps, clamp expressions and responsive padding. Preserve each component's values when moving markup. Radius and shadow tokens below coexist with local card/form overrides.
